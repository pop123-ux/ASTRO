\section{ASTRO Baseline Provenance}
ASTRO entered the ORBIT campaign as a pre-existing frozen baseline. The code identifier
\texttt{astro\_v2} was the final recipe selected during the preceding ASTRO study, not a
variant selected using ORBIT results. In the historical 124M/900-step targeted mechanism
study, the mean loss margin versus Muon across three shared configurations was approximately
$-0.2208$ for the final ASTRO recipe, compared with $-0.2137$ for ASTRO-Muon-Betas and
$-0.2047$ for the gamma-zero control. At one shared configuration, however, final ASTRO and
ASTRO-Muon-Betas were effectively tied (5.9208 versus 5.9226). Earlier plain ASTRO recipes
also failed to beat Muon in some controlled experiments. These measurements justify using
the final frozen recipe as the representative ASTRO baseline while avoiding a claim that it
dominated every development variant in every setting. These historical measurements belong
to the preceding ASTRO development program and are not pooled with the ORBIT campaign's
confirmatory statistics.
