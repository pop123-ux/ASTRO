\begin{abstract}
Modern matrix optimizers treat query and key projection matrices as ordinary parameter
operators even though rotary attention couples them through position-dependent bilinear
interactions. ORBIT is an optimizer-only method that uses frequency-local $2\times2$
statistics to precondition query/key updates according to their predicted movement in
rotary attention-logit space while preserving standard inference-time weights. This
manuscript scaffold is generated from a frozen evidence manifest; final prose is written
only after the artifact validation gate passes.
\end{abstract}

\section{Introduction}
The central question is whether an optimizer for rotary attention should measure a query/key
step only in raw parameter space or in the function induced on attention logits. ORBIT tests
the latter hypothesis while retaining ordinary Transformer weights and the standard
inference graph. The empirical design deliberately separates optimizer mechanism from
hyperparameter recipe before testing mechanism ablations and transfer.

\paragraph{Contributions.}
The intended contributions, subject to the final equation-level prior-art audit, are:
\begin{enumerate}
  \item a cheap RoPE-aware local metric for joint query/key optimization based on
  frequency-pair statistics;
  \item an optimizer implementation that preserves the total Q/K update norm after
  functional preconditioning and changes no inference computation;
  \item a matched-hyperparameter confirmation designed to isolate the optimizer mechanism
  from tuning-recipe effects;
  \item ablations that isolate generic Q/K functional conditioning, RoPE-aware rotation,
  and full off-diagonal phase coupling;
  \item longer-horizon and 355M transfer tests reported with their limited seed counts
  explicitly visible.
\end{enumerate}

\section{Related Work and Novelty Boundary}
ORBIT is not a claim to invent optimization of QK/OV products, low-rank quotient geometry,
Muon-style spectral descent, or architecture-aware optimization. Knight's recent
Riemannian optimizer explicitly treats QK/VO products as rank-constrained optimization
objects while preserving factorized implementations~\cite{knight2026}. The present work
instead targets the setting in which RoPE makes the query--key interaction
relative-position dependent. This section must be refreshed from the final dated
equation-level prior-art audit immediately before public submission.

\section{Limitations}
The local metric is an approximation to rotary attention-logit function space rather than
an exact natural gradient. The matched effect is smaller than the original independently
tuned ORBIT--Muon gap, demonstrating that tuning recipe materially affects headline
optimizer comparisons. The off-diagonal ablation must be reported even if it does not
establish a benefit. The long-horizon and 355M transfer cells use only two paired seeds and
therefore provide transfer evidence rather than high-powered inferential tests. The 355M
batch/token regime also differs from the 124M experiments, so the paper must not claim that
the ORBIT advantage grows with model scale from these cells alone.

\section{Reproducibility}
All runs are append-only JSONL records containing the optimizer configuration, random seed,
code digest, Python/package environment, GPU model, wall-clock time, validation loss,
training curve, and peak CUDA allocation. Paper generation is gated by a strict evidence
freeze that checks exact task counts, expected seeds, the frozen core digest, a common
software environment, identical matched configurations, and finite metrics before writing a
manifest, claim ledger, tables, or figures.
